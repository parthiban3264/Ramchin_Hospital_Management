# 🏥 Hospital Management System

A comprehensive **Hospital Management System** designed to digitize and streamline day-to-day hospital operations through a centralized platform.

The system provides **role-based access** for Admins, Doctors, Nurses, Cashiers, Lab Technicians, and Pharmacy staff, enabling each department to manage its operations efficiently.

---

## ✨ Key Features

### 🔐 Role-Based Access Control

Dedicated workflows and permissions for:

* 👨‍💼 **Admin**
* 👨‍⚕️ **Doctor**
* 👩‍⚕️ **Nurse**
* 💳 **Cashier**
* 🧪 **Lab Technician**
* 💊 **Pharmacy / Medical**

Each role has access only to the features required for their responsibilities.

---

## 👨‍💼 Admin Management

The Admin has complete control over hospital operations.

* Manage hospital services and staff
* Create, update, and delete staff accounts
* Manage Doctors, Nurses, and other staff
* Activate staff accounts
* Reset passwords
* Assign staff fees and duty schedules
* Manage rooms and bed availability
* Manage pharmacy and medicine inventory
* Manage medicine suppliers
* Bulk medicine stock upload
* Manage tests and scans
* View hospital statistics
* Generate hospital reports
* Manage income, expenses, and drawings
* View daily, monthly, and yearly financial reports

---

## 👨‍⚕️ Doctor Management

Doctors can manage both **Out-Patient (OP)** and **In-Patient (IP)** workflows.

* Manage OP and IP patients
* Create prescriptions
* Order laboratory tests and scans
* View doctor-specific patient statistics
* Access authorized administrative features
* Permission-based Admin access

---

## 👩‍⚕️ Nurse Management

Nurses can manage patient care and treatment workflows.

* Patient registration
* Test and scan patient registration
* Record patient vitals
* Manage patient queues
* Handle injections and treatments
* Manage in-patient treatments
* View assigned-patient statistics

---

## 💳 Billing & Cashier Management

The Cashier module handles hospital billing and financial transactions.

* Registration payment collection
* Test and scan payment collection
* Generate and print **4-inch PDF bills**
* View payment history
* Manage in-patient admission
* Change patient beds
* Patient discharge management
* Check room availability
* Add room charges
* Daily, monthly, and yearly financial reports

---

## 🧪 Laboratory Management

The Laboratory module manages tests, scans, and medical results.

* Conduct tests and scans
* Enter test results
* Enter scan values
* Generate test reports
* View test history
* Create new test types
* Create new scan types

---

## 💊 Pharmacy Management

Complete medicine inventory and sales management.

* Manage medicine stock
* Track inventory
* Manage suppliers
* Handle medicine sales
* Process medicine payments
* Generate medicine bills
* Monitor stock levels
* Generate medicine sales reports

---

## 👤 Common Features

Available across the system according to user permissions:

* Personal profile
* Edit profile
* Change password
* Secure logout
